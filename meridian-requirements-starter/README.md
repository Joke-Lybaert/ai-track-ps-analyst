# Meridian Complaint Management System. Requirements Workspace

This is your team's working folder for the day. Everything you produce. the backlog,
glossary, diagrams, decisions, open questions. lives here as plain markdown files, so your
whole team (and your AI tool) can read and edit them directly.

## Files you'll build on today

- `backlog.md`. the user story backlog and acceptance criteria (Pair AB starts this in Block 1)
- `glossary.md`. the domain glossary (Pair CD starts this in Block 1)
- `decisions.md`. your team's running log of decisions made during the day
- `open-questions.md`. anything that needs a client/stakeholder answer, not a team decision

These four are just a starting point. Later blocks will have you add more (a domain model
diagram, a business rules catalogue, a requirements package). create new markdown files for
those as you go. There's no fixed template beyond what the prompt ladders ask for.

## Working in this repo

Edit these files the same way you'd edit any document. by hand, or by asking your AI tool to
read and edit them for you (that's what Block 2's agent-mode exercise is about). Nothing here
needs to compile or run; it's just structured text.

If you don't have anything installed and are working from a browser only, see the "no
install" option in `block2-prompt-ladders.md` and `block3-prompt-ladders.md`. this repo works
the same way whether you open it locally, in an IDE, or in a GitHub Codespace.
