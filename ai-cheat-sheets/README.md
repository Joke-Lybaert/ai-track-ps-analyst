# AI Cheat Sheets: Functional Analyst

Short, practical guides for the AI tools that matter most for your work as a functional
analyst. These are not required reading before the workshop, but if you have little or no
experience with AI tools, start here rather than jumping straight into the exercises.

If you already use these tools regularly, skim them anyway: there may be a feature you haven't
tried.

## What's here

- [`copilot-chat.md`](copilot-chat.md): which AI chat tool to use today (M365 Copilot, GitHub
  Copilot, Claude.ai or your own favourite), and how to use it well with no coding and no IDE.
- [`mermaid.md`](mermaid.md): turning a description into a diagram using plain text, used
  repeatedly through the day.
- [`claude-ai-custom-connectors.md`](claude-ai-custom-connectors.md): setting up the browser-based
  AI tool and connector used in Block 3.
- [`what-is-mcp-for-analysts.md`](what-is-mcp-for-analysts.md): a plain-language explanation of
  what you're actually connecting to in exercise 3, and why it matters.
- [`atlassian-rovo.md`](atlassian-rovo.md): not part of today's workshop, but the AI tool a lot of
  analysts actually use day to day. Worth knowing what it can do.

If something breaks and these guides don't cover it, see `../../ai-tooling-fallback.md` or ask
your coach.
